# La Villa Pilates — website concept

Premium one-page React/Vite proposal website for La Villa Pilates in Abidjan.

## Run locally

```bash
npm install
npm run dev
```

## Demo content

- `public/images/*-placeholder.png`: original AI-generated editorial demo imagery.
- `public/images/instagram-reference/`: temporary public listing images from BAAB. Confirm rights with the studio before publishing.
- Schedule, pricing, coach names, testimonials, email, form delivery and English localization are placeholders.
